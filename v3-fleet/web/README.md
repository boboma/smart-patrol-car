# web/ — 网页端

## 当前已有

### admin.html — 管理后台（步骤⑤，v1.2，面向管理员）

纯静态单文件页面，零依赖、零构建。**浏览器直接双击打开即可**（后端已放行
CORS，含 X-Admin-Token 自定义头的预检）。

顶栏四个视图：总览（在线/离线/冻结统计 + 电量排行 + 7 天消息量条形，10s 自动刷新）/
设备管理（列表 + 注册新设备 + 冻结/解冻）/ 命令历史（commands.log 结构化表格）/
实时监控（内嵌 fleet_view.html）。

- 登录：默认 admin / admin123（见 server/config.json），token 存 localStorage，
  后端重启 token 失效后 401 自动弹回登录卡片
- 注册成功的密钥**只显示一次**（醒目黄色卡片），提示复制保存
- 用法与"注册→使用→冻结"闭环操作顺序见根 README「管理后台」一节

### fleet_view.html — 车队监控与回放主页面（步骤④，面向演示）

纯静态单文件页面，零依赖、零构建。**浏览器直接双击打开即可**（后端已放行
CORS，file:// 打开能正常工作）。

顶栏可切换两个视图：

1. **实时监控**（协议 7.1 主通道 + 7.2 兜底）
   - WebSocket 连 `ws://<后端host>:8889/ws`，每 1 秒收一帧 `fleet_state`，
     每车一个彩色箭头按 heading 旋转，运动时留下同色轨迹线（每车最多 80 点）
   - 左侧车辆面板：色块 + 名称 + 在线状态 + 电量 + 坐标；勾选框控制画布上
     显示哪几辆；单击卡片"聚焦"该车（只画它的轨迹且加粗），再点取消
   - 断线指数退避重连：1s→2s→4s→…→30s 封顶（V1 car_view 同款写法）
   - WS 连续失败 3 次自动降级：每 2 秒轮询 `GET /fleet/status`（协议 7.2），
     页面顶部出现"HTTP 兜底模式"提示；WS 恢复后自动切回
   - 帧间位置线性缓动平滑（首帧/大跳变直接贴合不动画）
2. **轨迹回放**（协议 7.3）
   - 选车下拉框 + 时间窗（datetime-local，留空默认最近 1 小时）→「加载轨迹」
     调 `GET /track`，画布先画出灰色完整轨迹
   - 播放/暂停、×1/×4/×16 速度、可拖动进度条；播放时彩色覆盖已走部分，
     小车标记沿轨迹移动并显示当前点时间戳

本页定位是**只看不控**（协议 L4）：没有任何控制按钮，控车请用 test_console。

### test_console.html — 接口测试台（步骤② 配套，手动测试用；步骤⑦ 增 AI 语音控车卡）

纯静态单文件页面，零依赖、零构建。**浏览器直接双击打开即可**（后端 app.py 已放行
CORS，file:// 打开能正常调接口）。

用法：

1. 先启动设备端与后端：
   - `device/start_fleet.py`（双车模拟器）
   - `server/app.py`（业务后端 :8000，同时会拉起 :8889 的 WS 广播与 FunASR 后台预热）
2. 双击打开本页，右上角自动探活，显示"在线 · 2 台 / 2 台在线"即链路就绪
3. 左侧选车 → 方向盘发命令（FORWARD/BACK/LEFT/RIGHT/STOP + speed 滑杆）
4. 「车队状态」看双车位置/电量快照；「选中车实时状态」可开 2s 轮询
5. 「错误用例」四个按钮验证协议 4.5 的 400 拦截（不碰真车）
6. 所有请求进底部日志，点开可看完整 JSON 响应

**AI 语音控车卡**（步骤⑦，v1.4，协议文档第 16 节；位于控制台卡下方）：

- 「按住说话」大按钮：mousedown/touchstart 开始录音（录中变红显示秒数），
  mouseup/touchend 停止。WebAudio 方案：`AudioContext({sampleRate:16000})`
  （浏览器自动重采样到 16k）+ ScriptProcessor 收 Float32 → 拼 Int16 →
  手写 44 字节 WAV 头 → `POST /ai/asr` 拿文字 → 再 `POST /ai/command` 执行
- 文字指令：输入框直接打字回车/点「执行」，只走 `/ai/command`
- 对话区：[你说] 原文 → [AI] 确认话术 → [执行] 每条动作 ✓/✗（失败带原因）
- 控制目标跟随左侧选中车：选了车 = 指令只发这台车（device_id 优先）；
  没选车 = AI 听话里的车号（"1号车"→car_001）
- 麦克风权限被拒/浏览器不支持：对话区显示红色提示并禁用按钮（文字指令仍可用）
- 常见问题：file:// 下 Chrome/Edge 可正常用麦克风；识别失败先看后端
  控制台（FunASR 首次加载约 30 秒，期间请求会等模型就绪）

## 两个页面的分工

| 页面 | 面向 | 回答的问题 |
|---|---|---|
| `fleet_view.html` | **监控演示**（大屏/课堂展示） | "车队现在怎么样了？刚才走过的路长什么样？" |
| `test_console.html` | **接口调试**（开发阶段测试） | "每个接口的请求/响应长什么样？错误码拦不拦得住？" |
| `admin.html` | **运营管理**（管理员日常） | "设备怎么注册/冻结？命令历史有没有？消息额度还剩多少？" |

三页并存、互不替代：演示时开 fleet_view，调接口时开 test_console，管设备时开 admin。

## WS 自测脚本

`server/test_ws.py`（见 server/ 目录）：连 8889 收 3 帧 fleet_state 校验结构、
验证 ping→pong 心跳，打印 PASS/FAIL 汇总。先启动 app.py，再运行：

```
cd v3-fleet\server
D:/anaconda3/python.exe test_ws.py
```
